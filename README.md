# 📊 Sales & Profit Analysis Project

## 📌 Overview
This project analyzes **sales, profit, and units sold data** across multiple dimensions such as **month, country, product, and customer segments**.  
The dataset was processed in **Excel** using pivot tables, charts, and dashboards to uncover insights into business performance.

---

## 📂 Dataset Details
The dataset includes:
- **Sales by Month** (September–December, 2013–2014)
- **Profit by Month**
- **Sales & Profit by Country**
- **Sales & Profit by Product**
- **Segment-wise Units Sold**
- **Year-wise Sales**
- **Cost of Goods Sold (COGS)**
- **Margins & Discounts**

---

## 📈 Key Insights
- **Highest Sales Month:** October (₹9,295,611)  
- **Highest Profit Month:** October (₹1,657,795)  
- **Top Performing Product (Sales):** Velo (₹6,197,299)  
- **Top Performing Product (Profit):** Paseo (₹1,099,853)  
- **Country with Highest Sales:** Germany (₹6,227,735)  
- **Country with Highest Profit:** Germany (₹1,118,219)  
- **Largest Segment (Units Sold):** Government (123,431 units)
